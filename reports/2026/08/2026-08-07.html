With Anthropic's Managed Agents Multi-Agent Orchestration now in public beta, the lead-agent/worker-agent fan-out pattern is production-ready. Structure a lead agent that decomposes a task ("audit every SwiftUI view for dark-mode issues") and dispatches slices to specialist sub-agents — each with its own tool allow-list and a hard tool-call ceiling — then aggregates results through a verifier pass. Tool Use Enforce Structured Outputs So Agent Tool Calls Are Codable in Swift

The #1 source of agent-loop crashes isn't the model — it's unparseable tool-call arguments. Turn on strict structured outputs (OpenAI strict: true, Anthropic tool input_schema, Apple Foundation Models @Guide) so every tool call returns JSON matching a schema you own, then decode it in Swift with JSONDecoder + Codable structs. Malformed calls now fail at the type boundary instead of mid-execution, and your agent loop becomes as reliable as a network API. Define one schema per tool, reject anything that doesn't validate, and log the rejection so you can tighten the prompt. Structured outputs →

RAG Hybrid Retrieval + Re-Ranking: Cut Agent Hallucinations on Your Docs

Pure vector search misses exact-match queries (error codes, transaction IDs); pure keyword search misses synonyms. Run a hybrid retriever (BM25 + dense embeddings, score-fused) and pipe the top-20 through a cross-encoder re-ranker to surface the 3–4 truly relevant chunks — then feed only those to the model. The payoff: 30–50% fewer "I couldn't find it" hallucinations on support/RAG agents, plus a smaller context window (cheaper and faster). On-device, MLX embeddings + SQLite FTS5 give you the same hybrid pattern locally with zero data egress. Hybrid retrieval primer →
