💡 Daily Tech Tips — Sunday: Best of Week (Claude Code Agentic Workflow, Anchored on the Aug 25–28 Changelog)
Claude Code · Hooks Gate Model Switches With PreModelSwitch / PostModelSwitch Hooks

Claude Code 2.1.251 (Aug 28) added two new hook events — PreModelSwitch and PostModelSwitch — that let you block, confirm, or annotate a model switch mid-session. The deployable shape for a Binance iOS workflow: write a PreModelSwitch hook that blocks a mid-task downgrade to a cheaper/dumber model (so a long refactor doesn't silently drop to a weaker tier) and logs every switch to an audit file, then pair PostModelSwitch with a status-line script to surface the active model + effort level. It's the hooks primitive (cf. the Monday agentic-workflow thread) now applied to model governance — the agent's model choice becomes an auditable, gateable event instead of a hidden toggle. Changelog →

Claude Code · Security Run Untrusted PRs in --restricted Mode — No Command/Code Tools, WebFetch Jailed, Files Locked to the Working Dir

Claude Code 2.1.248 (Aug 27) added --restricted (or CLAUDE_CODE_RESTRICTED=1): it removes the built-in tools that run commands or code and WebFetch (unless named in --tools), keeps file tools inside the working directory, refuses bypassPermissions, and ignores user/project/local settings files. For reviewing an external contributor's PR or running Claude Code against an untrusted repo, this is the least-privilege posture (Aug 21/27's agent-safety thread) made the default — the agent can read and edit within the repo but can't shell out, fetch the web, or escalate permissions. Add it to your PR-review command as the safe baseline, then allow only the specific tools the review needs via --tools. Restricted mode →

Claude Code · Cost Set a Hard Spend Ceiling + Spot Runaway /loop Tasks With the New /usage Loops Breakdown

The Aug 25–28 changelog shipped the tooling behind the agent-loop-budget practice (Aug 22): a Spend limit bar in /usage and a rate_limits.spend_limit status-line field for accounts behind a Claude apps gateway, plus a per-loop breakdown in /usage (run count, total tokens, tokens/run, last run — 2.1.243). The deployable loop for a team running parallel agents: set a spend_limit that caps a runaway /loop before it eats the weekly budget, then scan the Loops breakdown to find the chatty agent (high tokens/run = real workload or stuck retry) and either tighten its maxTurns or abort-and-discard. Cost control moves from "guess after the bill" to a hard ceiling plus per-loop telemetry — pair it with the new /claude-api cost-optimize (2.1.247) to walk the cost levers (caching, token hygiene, batch, effort, model choice) one measured change at a time. /usage + loops →
