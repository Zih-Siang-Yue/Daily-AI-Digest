Cursor · Rules Make Context Deterministic With .cursor/rules/*.mdc Glob-Attached Rules + @-Mention Pinning

Cursor’s MDC (Markdown Config) rule files let you write one convention per concern and auto-attach it by file-glob — a .cursor/rules/swift-style.mdc with globs: ["**/*.swift"] injects only when the agent edits Swift, so a 12-rule repo doesn’t bloat every session. Pair it with explicit @Files / @Folder / @Codebase pinning so the Composer reasons over the files you named, not whatever semantic search surfaced. Why it matters: it’s the Cursor-side deterministic-context-control move (the editor analog of AGENTS.md, Sep 21) — and on a large iOS codebase it’s what stops the agent from dragging a deprecated UIKit reference into a SwiftUI feature. How to use it: split rules by glob (language, module, tests), mark only the cross-cutting ones alwaysApply, and @-pin the exact files for any multi-file edit so the context window is auditable. Copilot · Agent Drive the Copilot Coding Agent Issue→PR With .github/copilot-instructions.md and a Required Review-Gate

GitHub’s Copilot coding agent takes a well-formatted Issue, proposes a plan, implements across files, runs CI, and opens a PR — and like Claude Code it reads a repo-level instruction file (.github/copilot-instructions.md) for conventions, forbidden paths, and the review-checklist. Why it matters: it’s the Copilot-advanced step beyond Sep 16’s “agent mode”: instead of inline suggestions you assign a bounded engineering task to the agent and gate the merge on a required Copilot-code-review status check + a human approval, turning it into a PR-producing teammate with a deterministic backstop. How to use it: write the Issue with an explicit definition-of-done + tests, mirror your AGENTS.md into the Copilot instructions file, and require the review status check before merge — same sandwich discipline (Sep 18), editor-native. Copilot coding agent →

Windsurf · Memory Codify Long-Lived Conventions in Windsurf Memories + Cascade Rules, and Checkpoint Multi-Session Refactors

Windsurf’s Memories persists architectural decisions and project facts across sessions (so a multi-day SDK-migration refactor doesn’t re-explain the module map each morning), and Cascade rules codify conventions the agent must honor — the persistence layer that makes a long-horizon run survivable across restarts. Why it matters: it’s the missing piece between durable-execution (Sep 16) and orchestrator-worker dispatch (Sep 21) — and checkpointing after each session means a context-rotted Cascade run can’t corrupt the shared state. How to use it: write the non-obvious architecture facts into Memories, version Cascade rules in the repo, and end each session by writing a one-paragraph checkpoint the next run reads first. Weave Router 2.0 (WebSearch) is a source-available dynamic model router for multi-step agent pipelines: it assesses each step’s complexity and routes that reasoning turn to the lowest-cost model capable of completing it — the operationalization of the model-cascading/SLM-first concept (Sep 17) as a standalone product. 🔥 Hot Industry Concepts
Architecture Compound AI Systems — Stop Building “a Prompt,” Start Building a System of Evals + Tools + Caches + Guardrails

The 2026 architecture frame that has overtaken “LLM app” thinking: a Compound AI System composes a (small/specialized) model with deterministic components — retrieval, tools, caches, verifiers, and guardrails — where the system’s correctness is measured by evals on the whole pipeline, not the model alone. Why it matters NOW: it’s the unifying frame behind today’s Prompt-Caching Dashboard and Weave Router cards and the multi-agent topologies (Sep 21) — and it reframes the engineer’s job from “prompt tuning” to “system design with a non-deterministic component,” which is the lens that makes a Binance trading/compliance agent auditable. How to use it: for every agent feature, write the eval set first, test the full pipeline (not the model), and treat the model as the swappable component inside a deterministic scaffold. BAIR →

FinOps · Agents Agent Economics & Context Budgeting — Per-Run Token/Context/Cost as a First-Class Ops Metric

As agents run for hours across many turns, token spend, context-window fill, and cache hit-rate have become first-class observability metrics — with dedicated tooling: OpenAI’s Prompt Caching Dashboard (today), dynamic model routers (Weave Router), and prompt/context compressors (Edgee Codex Compressor). Why it matters NOW: it’s the agent-specific layer above infra FinOps (Sep 22) — a 4-hour coding-agent run at a 50% cache-miss rate costs ~2× the same run at 90% hits, and without per-run tagging that bleed is invisible until the invoice arrives. How to use it: tag every agent run with model + tokens + cache-hit, set a per-run cost SLO, and alert on cache-miss spikes as the leading indicator. FinOps Foundation →

CI/CD Agentic CI/CD & Self-Healing Pipelines — Agents That Don’t Just Write the Build, They Fix It When It Breaks

The next step past “agent writes the code” is the agent owns the build: when CI fails, an agent reads the log, diagnoses, and opens the fix PR — closing the loop without a human on the on-call. Why it matters NOW: it’s the concept the OpenCodeReview/SpecShip products (Sep 21–22) point at — agents as first-class CI/CD participants that triage and repair failed pipelines, not just code-generators — and it’s the natural home for the deterministic-guardrail sandwich (Sep 18): the self-healing loop is only safe because each step is gated in code. How to use it: give the agent a bounded “fix this failing build” task with a max-attempts cap and a required-green-tests gate; never let it merge its own fix. Anthropic agents →
