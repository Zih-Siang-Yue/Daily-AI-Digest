💡 Daily Tech Tips — Edge AI / On-Device ML (ANE · MLX · Core ML)
Edge AI · Profiling Profile Prefill and Decode Separately — They're Bottlenecked by Different Hardware

On the Apple Neural Engine (ANE) the prefill phase (processing the prompt) is compute-bound and saturates the systolic array, while decode (token-by-token generation) is memory-bandwidth-bound and stalls on LPDDR5X (~60–100 GB/s), capping a 3B model at roughly 15–30 tok/s. Why it matters: collapsing them into one "latency" number hides that context length inflates decode cost superlinearly — so a feature that feels snappy at 256 tokens dies at 2K. How to use it: measure tok/s at a fixed prompt length and a fixed decode length independently; size the feature's context window to the decode budget, not the prefill budget. Apple ML →

Edge AI · KV-Cache Use Grouped-Query Attention + Cross-Layer KV-Cache Sharing to Fit Decode in the ANE Memory Budget

The decode-phase memory wall is the #1 reason an on-device LLM OOMs a Binance iOS feature; Grouped-Query Attention (GQA) (share K/V heads across query heads) and cross-layer KV-cache sharing cut the per-token activation footprint by roughly 4–8× with negligible quality loss. Why it matters: it's the architectural lever Apple's own ~3B Foundation Model uses to stay resident inside 8 GB of Unified Memory — so it's the one trick that turns a 1.5B model crashing under jetsam into a 3B model that holds. How to use it: when converting to .mlpackage via coremltools, set the GQA config and enable cross-layer sharing; assert KV-cache peak RSS against os_proc_available_memory() on a low-RAM device before shipping.

Core ML · Compute Units Force Static-Shape Layers to the ANE and Bucket Sequence Lengths — Stop the GPU-Fallback Tax

Core ML splits a compute graph by target: static-shape layers compile to the ANE for best battery/thermal, but dynamic sequence-length ops JIT-recompile or fall back to the GPU (Metal), spiking power draw. Why it matters: a model that "works" on the simulator can throttle and die in production once real prompts hit variable lengths. How to use it: set compute_units = ComputeUnit.ALL (or ANE_AND_NE where exposed), bucket sequence lengths to a fixed set (e.g. 128/512/2048) and pad, then read the Core ML compute-unit report — every GPU-fallback line is a battery/thermal bill you can often eliminate with a re-export.

OpenAI Disrupts a Coordinated Campaign to Distill Its Protected Model Reasoning

OpenAI reported (Sep 30, RSS-verified) that it disrupted a coordinated campaign to extract its models' protected chain-of-thought reasoning — adversarial distillation that would let a competitor cheaply clone frontier capability without training it. Why it matters: the first public distillation-defense counter-op reframes "model weights are the moat" into "the CoT is the moat, and we monitor it" — a defensive discipline directly relevant to any agent leaking its reasoning to a log. How to use it: treat your agent's exposed reasoning traces as exfiltratable secrets — rate-limit reasoning visibility, redact trace outputs in logs, and gate chain-of-thought exposure behind an auth boundary. (RSS-verified; openai.com/index/disrupting-a-coordinated-model-distillation-campaign, real Sep 30 URL.)

How to use it: lift Astra's failure classes (deceptive agent behavior, unauthorized tool use) into your own pre-ship eval rubric; a green eval is a release gate, not a recommendation.
