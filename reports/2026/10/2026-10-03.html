Edge AI · Preflight The 4-Gate Preflight — A Single Checklist for Shipping an On-Device LLM Feature

Consolidating the week’s highest-leverage edge-AI moves into one reviewer-run gate: (1) decode budget — measure tok/s at a fixed decode length, not just prefill; (2) KV-cache peak RSS — assert against os_proc_available_memory() on a low-RAM device; (3) compute-unit scan — every GPU-fallback line in the Core ML report is a battery/thermal bill; (4) jetsam survival — the feature must not crash under a memory warning. Why it matters: a feature that passes all four gates is the difference between “works on my simulator” and “works in a Binance user’s pocket at 2K context.” How to use it: make the checklist a required PR comment for any on-device-LLM feature; a fail on any gate is a ship-blocker. Edge AI · Specialization Pin the 4-Bit Base, Hot-Swap LoRA — Many Task Heads at ~0× the Footprint

The week’s most-impactful pattern replayed: ship one 4-bit base .mlpackage resident in memory and swap per-feature LoRA adapters (tens of MB) in milliseconds — the exact technique Apple’s ~3B AFM uses to power summarize/code-complete/intent from a single resident model. Why it matters: specialization (summarize ≠ codegen) at ~0× the memory cost of a second SLM — the single move that turns a 1.5B crashing under jetsam into a 3B that holds. How to use it: export each adapter via coremltools.optimize (palettize 4-bit), load the base once, swap the adapter handle per call, and assert the LoRA-merged output equals the full-merged model on a held-out set before ship. Apple ML →

Distribution · Cost Never Ship Multi-GB Weights in the IPA — Background-Assets + mmap & Decouple Model Updates from App Updates

A 4-bit 3B model is ~1.8–2.2 GB; bundling it in the IPA blows cellular limits, inflates install size, and couples model freshness to App Review. The week’s distribution-layer fix replayed: declare a Background Assets download in Info.plist, pull weights post-install into Application Support/, then mmap read-only so pages are shared with the OS file cache and survive a memory warning by eviction without copy. Why it matters: it’s the move that gets an on-device LLM past App Review and lets you ship a new adapter without a new binary. How to use it: ship a thin loader, stream into the container, assert the mapped region is valid before first inference. Background Assets →

🔥 Hot Industry Concepts
Retrieval GraphRAG — Knowledge-Graph-Augmented Retrieval for Grounded Agent Memory

As corpora grow, plain vector RAG dilutes signal — GraphRAG ties chunks into a typed knowledge graph so retrieval returns related context plus provenance and edges, not just nearest-neighbour blobs. Why it matters NOW: it’s the structure that stops an in-app agent from hallucinating an API or trade-flow it doesn’t actually have — the grounded-memory layer between Context Engineering (Sep 29) and the agent’s working set. How to use it: build a small typed graph of your domain entities, attach retrieved chunks as graph leaves, and return the subgraph (not the raw chunks) to the prompt; cite edges back to source. GraphRAG →

Agent Routing Edge Decision Models — Sub-100ms Branching Classifiers That Front-Run the Frontier Call

Distinct from the SLM+LLM cost-cascade (Sep 29), the edge decision model pattern uses tiny open-weight classifiers (Cloudflare Clef, released today, is the instance) to resolve typed branching logic — schema validation, intent classification, guard checks — in milliseconds, so the frontier model only sees the one path that survived. Why it matters NOW: it turns “route-then-reason” from a prompt-level heuristic into a deterministic, auditable pre-LLM layer — the routing primitive the SLM+LLM topology was missing. How to use it: put a Clef-class model in front of every frontier call; log the branch decision and the model trace separately so the router is debuggable, not a black box. Cloudflare Clef →

Runtime Isolation eBPF Agent Sandboxing — Kernel-Level Syscall/Network Policy for Autonomous Agents

Where the governance plane (Sep 28) says which tool an agent may call and Claude Code hooks (Sep 28) gate at execute time, eBPF enforces the policy in-kernel — intercepting syscalls and network egress with near-zero overhead, in a boundary an agent prompt cannot talk its way past. Why it matters NOW: it’s the missing isolation primitive for agents that run shell + MCP tools (the Heapjack-class escape Sep 22 argued for); NVIDIA OpenShell (Sep 29) is the user-space version, eBPF is the kernel floor. How to use it: run each unattended agent under an eBPF policy denying outbound egress except an allowlist; alert on any denied syscall. eBPF →
