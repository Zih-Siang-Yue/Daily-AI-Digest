💡 Daily Tech Tips
AI × iOS Run Core ML (ANE) and MLX (GPU) Concurrently — They’re Independent Silicon, Not a Zero-Sum Budget

On Apple Silicon the Neural Engine and the Metal GPU are physically separate compute blocks sharing one Unified Memory bus, so a Core ML vision/audio pipeline on the ANE and an MLX generative LLM on the GPU can run simultaneously without compute contention. Why it matters: the hybrid pattern (sensor/feature extraction on ANE → generative reasoning on GPU) is the only way a Binance iOS feature can do live camera OCR and an on-device rewrite in the same frame without dropping the UI. How to use it: wrap each engine in its own Sendable actor, drive them from separate Task priorities, and assert in Instruments that neither timeline blocks the other. Apple ML →

Edge AI Throttle MLX Generation From thermalState — Cut Spec-Decoding Before jetsam Cuts You

Sustained MLX inference runs on the Metal GPU and pushes thermals fast; once ProcessInfo.processInfo.thermalState hits .serious or .critical, the OS will either throttle the GPU or kill your process via jetsam — the user just sees a crash. Why it matters: this is the failure mode that survives the simulator but dies in a warm pocket, and it’s orthogonal to the memory-budget gate from last Thursday’s 4-Gate Preflight. How to use it: register a thermal-state observer, then step down a ladder — first drop speculative-decoding draft steps, then cut maxOutputTokens, then fall back to Apple’s system ~3B model (ANE, cooler) before letting the session stall. Thermal docs →

Core ML Pre-Compile to .mlmodelc in CI + Hot-Swap Backends via the LanguageModel Protocol

Running MLModel.compileModel(at:) on-device adds user-facing latency and can produce numerically inconsistent graphs across iPhone generations; the fix is to ship the compiled .mlmodelc bundle (Xcode/CI pre-build) and abstract the provider behind Apple’s LanguageModel protocol so the same UI code targets the system on-device model, an MLX custom model, or Private Cloud Compute. Why it matters: it kills both the cold-start tax and the vendor-lock-in tax in one move — and the protocol is the Swift-level answer to the multi-provider routing pattern carded across the harness tips last week. How to use it: compile in CI, load the .mlmodelc directly, and inject the backend via a protocol-typed session so a model swap is a config change, not a rewrite. Foundation Models →
