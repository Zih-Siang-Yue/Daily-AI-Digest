Cursor · Background Agents Spawn One Background Agent per Isolated git worktree — the Worktree Is the Rollback Unit

Cursor's Background Agents can run multiple Composer sub-agents concurrently; the production-safe move is to give each one its own git worktree so parallel refactors edit independent working copies and never clobber each other. Why it matters: the worktree-per-agent layout (the same pattern Codex CLI shipped Oct 6) brings real parallel delegation onto the laptop without a cloud round-trip, and the worktree — not the PR — is the rollback unit, so a derailed sub-agent is git worktree remove away from clean. How to use it: open one worktree per sub-task, point each Background Agent at its own path, and merge only the survivor branches — discard the rest. Cursor docs →

Copilot · CI Gate Wire Copilot Code Review to Protected Branches via the REST/GraphQL API — Then Watch ReviewBench Drift

GitHub's Oct-6 refresh made Copilot Code Review triggerable from CI/CD via REST/GraphQL (not just inline in the IDE), alongside the launch of ReviewBench — an open benchmark that measures AI review agents on precision, recall, and review depth against real production PRs. Why it matters: making the review a required status check closes the “AI writes → AI reviews → human verifies” loop (carded Sep 30) as a default-on gate; ReviewBench is the regression test that catches a silent Copilot downgrade before it reaches prod code. How to use it: call the review API from your Actions workflow on every PR, set the check required on main, and snapshot ReviewBench scores per Copilot version so a model swap is a measured change, not a vibe. Copilot →

Windsurf · Cascade Scope Cascade's Workspace Index to a Sub-Module Path — Don't Pull the Whole Monorepo Into Context

By default, a Binance-scale monorepo makes Cascade index every package and re-derive module boundaries each turn — burning context on symbols your task will never touch. Pin the workspace to a sub-path. Why it matters: it's the context-engineering move (Sep 29) applied at the IDE layer — a scoped index keeps the working set tight, lets the agent reason about the real call graph, and stops drift-induced hallucinations across package boundaries. How to use it: in codeium_config.toml set workspace_root to the target package, refresh the Cascade index, and only widen the scope when the agent explicitly hits a cross-package reference.
