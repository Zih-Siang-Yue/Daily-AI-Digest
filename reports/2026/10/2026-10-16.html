Tool Use · Structured Output Force Typed Function Calls With tool_choice: required — Stop Prompt-Begging for JSON

Both OpenAI and Anthropic APIs support tool_choice: "required", which forces the model to emit a structured tool call instead of free-form text. Pair it with a JSON schema in the tool definition and you get schema-locked output without "Return valid JSON" in the system prompt. Why it matters: prior tips gated edits (Blast Radius, Stop hooks, scoped tools) and model-pinned routers, but none addressed the output contract — tool_choice: required is the cheapest, most reliable way to ensure an agent emits parseable structured data. How to use it: define a tool with a zero-argument function where the properties are your schema, set tool_choice: "required", and never write "respond in JSON format" in the prompt again. Agent Arch · Loop Pattern ReAct vs Plan-and-Execute: Choose Your Agent Loop Before You Write Code

Two dominant loop patterns exist for agent pipelines: ReAct (observe → think → act, interleaved) for tasks requiring real-time tool feedback, and Plan-and-Execute (decompose upfront → execute steps) for multi-file refactors where the plan must be reviewed before execution. Why it matters: picking the wrong loop wastes tokens and time — ReAct on a 15-step migration means 15 round-trips of model inference, while Plan-and-Execute on a quick file edit means over-planning. How to use it: default to ReAct for single-tool tasks, switch to Plan-and-Execute when the plan has >5 steps or crosses >3 files, and let the model self-grade its plan before execution. Prompt Engineering · Cost Cut Agent-Loop Token Cost 80%+ With Provider-Side Prompt Caching

Both Anthropic and OpenAI now offer prefix caching: if your system prompt, instructions, and context block are identical across calls, the provider caches the KV states and charges a fraction of the input-token price on repeat calls. Why it matters: for agent loops that send the same 10K-token system prompt on every iteration, caching slashes input cost to 10-20% of the uncached rate — the single most effective FinOps lever for long-running agents, and the complement to agentic compute economics (Oct 15). How to use it: put stable content at the start of the prompt, mark the cache breakpoint, and verify you see the cache_read in the API response. Prompt caching →
